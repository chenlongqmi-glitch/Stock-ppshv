# Auto Deploy to Web & GitHub

Whenever any task, code edit, bug fix, or feature enhancement is made in this project:
- Automatically bump `version.json` with a new build timestamp.
- Automatically commit changes with a descriptive message.
- Automatically push to `origin main` on GitHub without waiting for user instruction.
- The web app on GitHub Pages (`https://chenlongqmi-glitch.github.io/Stock-ppshv/`) and all connected clients will automatically refresh and receive the update.
